CLASSROOM CLOCK & TIMER — POWERPOINT ADD-IN

1. Create a GitHub repository named classroom-clock-timer.
2. Upload taskpane.html, icon-32.png, and icon-64.png to the repository root.
3. In GitHub: Settings > Pages > Deploy from a branch > main > /(root).
4. Your site will normally be https://YOUR-USERNAME.github.io/classroom-clock-timer/
5. Open manifest-template.xml and replace every YOUR-USERNAME with your GitHub username.
6. Save it as manifest.xml.
7. In PowerPoint for the web: Home > Add-ins > More Settings > Upload My Add-in.
8. Upload manifest.xml.

FEATURES
- Live clock
- Visual countdown ring
- 1, 5, 10, 15, 20, 30 minute presets
- Custom timer 0.1–180 minutes
- Start / Pause / Reset
- Time's-up visual state + short tone

NOTES
- The hosted add-in works from Mac, Windows, and PowerPoint for the web.
- Manually sideloaded add-ins may need to be uploaded again in another browser/device.
- Timer state does not sync between devices.
- taskpane.html can also be opened as a standalone hosted classroom timer page.
